🔧 Configuration Options

Attribute Description Default
data-api-key Your Alitycs API key (required) -
data-sdk-url Custom SDK URL for self-hosting cdn.alitycs.com/sdk@2/browser.min.js
data-endpoint Custom API endpoint api.alitycs.com/events
data-auto-track Auto-track initial page view true
data-debug Enable debug logging false

💻 Example Configurations

Production (Minimal):

<script src="https://cdn.alitycs.com/snippet.min.js" data-api-key="your_production_key" async></script>

Self-Hosted:

<script src="https://your-domain.com/snippet.min.js" data-api-key="your_key" data-sdk-url="https://your-domain.com/sdk.min.js" data-endpoint="https://your-api.com/events" async></script>

Development (Debug Mode):

<script src="../dist/snippet.min.js" data-api-key="dev_key" data-debug="true" async></script>

Manual Page Tracking (SPA):

<script src="https://cdn.alitycs.com/snippet.min.js" data-api-key="your_key" data-auto-track="false" async></script>
