🚀 Alitycs Browser Snippet - Basic Example

This page demonstrates the ultra-lightweight Alitycs snippet in action. The snippet is loaded asynchronously and queues all calls until the full SDK is loaded.

💻 Code Examples

HTML Integration:

<script src="https://cdn.alitycs.com/snippet.min.js" data-api-key="YOUR_KEY" async></script>

Track an Event:

alitycs('track', 'button_clicked', { button: 'signup', page: 'homepage' });

Identify a User:

alitycs('identify', 'user_123', { email: 'user@example.com', plan: 'premium' });

Using Helper Methods:

// All these are equivalent: alitycs('track', 'event_name', { prop: 'value' }); alitycs.track('event_name', { prop: 'value' }); // Chainable: alitycs.track('event1').track('event2').identify('user_id');
