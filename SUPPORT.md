# Support

- Use [GitHub Discussions](https://github.com/alitycs/alitycs-sdk-js/discussions) for integration
  questions and usage help.
- Use [GitHub Issues](https://github.com/alitycs/alitycs-sdk-js/issues) for reproducible SDK bugs.
- Use [private vulnerability reporting](SECURITY.md) for security concerns.

Include the package version, runtime, relevant configuration with secrets removed, expected
behavior, actual behavior, and a minimal reproduction. General Alitycs product documentation is at
[docs.alitycs.com](https://docs.alitycs.com).
